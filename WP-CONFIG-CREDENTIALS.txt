===============================================================
  FREEWHEEL EXPEDITIONS — wp-config.php CREDENTIALS GUIDE
===============================================================

All sensitive credentials MUST be defined in wp-config.php.
They are NEVER stored in theme files.

STEP 1 — Open your wp-config.php file
  In cPanel / GoDaddy file manager:
  public_html → wp-config.php → Edit

STEP 2 — Find this line:
  /* That's all, stop editing! Happy publishing. */

STEP 3 — Paste these lines ABOVE it:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// ── FreeWheel Expeditions — Supabase config ──
define( 'FW_SUPABASE_URL',     'https://YOUR_PROJECT_REF.supabase.co' );
define( 'FW_SUPABASE_ANON',    'YOUR_ANON_PUBLIC_KEY_eyJhbGci...' );
define( 'FW_SUPABASE_SERVICE', 'YOUR_SERVICE_ROLE_KEY_eyJhbGci...' );

// ── FreeWheel Expeditions — Fast2SMS config (optional) ──
define( 'FW_FAST2SMS_KEY',     'YOUR_FAST2SMS_API_KEY' );

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WHERE TO GET EACH VALUE:
─────────────────────────────────────────────────────────
FW_SUPABASE_URL
  → Supabase Dashboard → Your Project → Settings → API
  → "Project URL"  (e.g. https://abcxyz.supabase.co)

FW_SUPABASE_ANON  (anon / public key)
  → Supabase Dashboard → Settings → API
  → "anon public" key  (long JWT starting with eyJ...)
  → This key is safe to be used in server-side PHP code.
  → It is NOT exposed to browser after this fix.

FW_SUPABASE_SERVICE  (service role key)
  → Supabase Dashboard → Settings → API
  → "service_role secret" key
  → ⚠️  NEVER share or commit this key anywhere.
  → Used server-side only for trusted database writes.

FW_FAST2SMS_KEY
  → fast2sms.com → Dashboard → Dev API Key
  → Only needed for SMS notifications on bookings.
  → Leave as empty string '' if not using SMS.

─────────────────────────────────────────────────────────
SECURITY NOTES:
  ✅  All keys live in wp-config.php (outside web root on GoDaddy)
  ✅  wp-config.php is excluded from git by .gitignore by default
  ✅  No keys appear in theme PHP, JS, HTML, or page source
  ✅  Supabase ANON key is NOT passed to frontend JavaScript
  ✅  Service role key is server-side only
